篝火堡垒 / HEARTHHOLD 0.6.2-preview
Windows x64 离线可玩原型

运行：解压到可写目录，双击 Hearthhold.exe。
需要 Windows .NET Framework 4.x。本机运行环境已验证。

0.6.2 更新：
战后可直接用三套预设补齐缺员；训练面板显示营位、金币等失败原因。
战斗中自动保存保留出征前兵力；整队打光且无队列时，营地会把金币补到80供重新训练。

0.6.1 更新：
修复战斗部署入口；按1—4选兵后可点击战场任意地块，系统会自动吸附到最近的绿色战线。

0.6 更新：
新增战前编队、兵种营位和原创训练队列；按T打开训练面板。
可逐个训练/解散兵种，也可排入均衡、重甲、远程三套45营位预设。
训练消耗金币并按现实时间逐个完成；取消最后一项全额返还，战斗中不显示完成，返乡后补算。
出征只消耗实际部署的单位，未部署部队在结算后返回聚落。
升级远征营可将单营容量从45提高到60/75，多座营地容量叠加。
建筑、兵种、光照、箭矢、重弹、塔箭、治疗和摧毁效果完成第二轮视觉升级。

0.5 更新：
新增10关原创战役、逐关解锁、最高星级与最佳破坏率记录。
新增5个成就与手动奖励领取；点击聚落左侧“战役/成就”查看。

0.2 更新：
建筑与兵种模型重做：屋瓦、拱门、砖石接缝、道具、武器和护甲。
新增确认拆除、50%资源返还、随主城等级变化的建造数量上限。
新增兵种图鉴、战斗右侧兵种介绍和首次出征教学。

第一次玩：
1. 点击左侧“收取产出”。
2. 选择底部建筑，再点击空地建造。
3. 点击主城，按 U 升级；选择建筑按 M 移动。
4. 按 I 看兵种图鉴，按 T 调整编队或训练兵种。
5. 点击右下角“出发远征”，阅读首次教学。
6. 点击战场任意地块投兵：先按3放铁卫吸引火力，再按4放破城手开墙，按1放先锋跟进，按2放游侠后排输出；单位会自动吸附到最近绿色战线。
7. 铁卫受伤后按 Q 选择治疗，点击士兵附近使用；每场两次，不能复活。
8. 打完后返回聚落，奖励和未部署士兵可以继续用于发展。

操作：
WASD / 中键：移动镜头
滚轮：缩放；Home：镜头复位
右键 / Esc：取消操作
M / U：移动 / 升级所选建筑
Delete：申请拆除所选建筑，确认后生效；议事堡不可拆
Ctrl+Z / Ctrl+Y：撤销 / 重做移动
C：收取资源；Ctrl+S：保存
1—4：切换兵种；Q：范围治疗
I：兵种图鉴，查看生命、伤害、射程、使用方法和弱点
T：战前编队、营位和训练队列
G：显示网格；F1：帮助并暂停；F11：全屏

内容：7类建筑、4类兵种、10个攻城关卡、5个成就、1种治疗法术（每场2次）。
首名士兵投下后开始计时；军队来自当前成军阵容，不会在每次远征后自动补满。
升级即时完成，最高3级，其他建筑受主城等级限制。

建造数量上限（议事堡1级 / 2级 / 3级）：
议事堡 1/1/1，金矿 3/4/5，晶露池 2/3/4，远征营 1/2/3，
重弩炮 2/3/4，哨塔 2/3/4，石墙 40/70/100。
底部建筑卡片显示当前数量；满额后需要升级主城或拆除同类建筑。
拆除返还建设及历次升级花费的50%，受仓储上限限制，已产生收益会先收取。
拆除不可撤销，也会清空移动撤销记录。拆掉最后一座远征营后，重建才能出征。

存档：程序旁 Saves/village.xml，上一份备份为 village.xml.bak。
每15秒及重要操作后自动保存。不要在同目录同时启动多个实例。
未结算的战斗不会续战；战斗中正常退出不给奖励并返还完整出征阵容。主存档损坏时尝试备份，不会自动覆盖两份损坏文件。
升级自0.1/0.2/0.4/0.5/0.6：退出游戏并备份Saves文件夹，再在原目录替换exe即可。
若解压到新目录，请手动复制旧Saves文件夹；本压缩包不附带存档。
旧存档里超过新上限的建筑全部保留，允许移动和拆除，但暂不能继续造同类建筑。

这是用于验证玩法的 Windows 原生试玩程序（WinForms/GDI+）。
Unity 3D 工程在源码中，与试玩程序共享 C# 核心逻辑、战役进度、训练编队及底层几何；另有独立的0.6.2 Unity 3D试玩包。本文件对应0.6.2轻量原生包。
