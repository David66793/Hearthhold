篝火堡垒 / HEARTHHOLD 0.6.3-preview
Unity 3D Windows x64 离线试玩版

运行：完整解压压缩包后，双击 Hearthhold.exe。
不要只复制exe；Hearthhold_Data、MonoBleedingEdge、UnityPlayer.dll及其他同级文件均为运行所需。
发布包运行时不需要安装Unity。

0.6.3更新：
六类建筑分别裁掉原图底部留白，并把立绘底边与地面占地对齐；建造预览与实际建筑使用同一高度。

0.6.2更新：
战后可直接用三套编队预设补齐缺员；训练面板会显示失败原因。
战斗中意外退出或异常关闭，存档会保留出征前兵力；整队打光且无队列时，营地会把金币补到80供重新训练。
Unity 建筑改为贴地的柔和接触阴影，兵种出手与防御建筑反击增加可见的位移、倾斜和后坐动作。

0.6.1更新：
修复进入进攻后鼠标输入、战斗推进和兵种显示被错误暂停的问题。
按1—4选兵后可点击战场任意地块，单位会自动从最近的绿色战线入场。
主堡、金矿、晶露池、远征营、重弩炮、哨塔和四类兵种已接入新的原创生成式画面。

0.6更新：
新增战前编队、45点初始营位和原创训练队列；聚落按T或点击“编队/训练”。
支持逐个训练/解散与均衡、重甲、远程三套预设；升级远征营提高容量。
训练按现实时间离线推进，战斗中不显示完成，返乡后补算；出征只消耗真正投下的单位。
建筑与四类兵种增加职业轮廓和材质层次；重新设计箭矢、重弹、塔箭、治疗与摧毁反馈。

0.5更新：
新增10关原创战役、逐关解锁、每关最高星级与最佳破坏率记录。
新增5个可领取成就；仓库空间不足时会保留奖励，消费资源后再领取。
聚落左侧“战役/成就”查看完整进度，底部箭头选择已解锁关卡。

0.4更新：
建筑选中圆环、带三维模型的建造与移动预览、清晰的投兵边界。
兵种平滑移动，新增远程弹道、近战冲击、治疗范围、受击闪光与摧毁碎片。
战斗面板显示存活/待命人数，血条根据危险程度改变颜色。

第一次玩：
1. 点击左侧“收取”，获得已经产生的资源。
2. 选择底部建筑，再点击地图空地建造。
3. 点击建筑，按M移动、按U升级、按Delete申请拆除。
4. 按I查看兵种说明，按T调整和训练本次远征阵容。
5. 点击右下角“出发远征”；按3选择铁卫后点击战场任意地块，系统会吸附到绿色战线。再按4放破城手开墙，按1放先锋跟进，按2放游侠后排输出。
6. 铁卫受伤后按Q，点击友军附近进行范围治疗；未部署士兵结算后返回。

常用操作：
WASD / 中键拖动：移动镜头
滚轮 / Home：缩放 / 镜头复位
右键 / Esc：取消操作
M / U / Delete：移动 / 升级 / 拆除所选建筑
Ctrl+Z / Ctrl+Y：撤销 / 重做建筑移动
C：收取资源
1—4：切换兵种；Q：范围治疗；I：兵种图鉴；T：编队与训练
F1：帮助；F11：全屏

存档位于Unity的Application.persistentDataPath，由系统按当前Windows用户管理。
原生试玩版与Unity版默认使用不同存档位置，不会自动互相覆盖。
未结算战斗不覆盖聚落存档；战斗中正常退出不给奖励并返还完整出征阵容。

验证环境：Unity 6000.6.0f1 / URP 17.6.0，Windows 11 x64。
