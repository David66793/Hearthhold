篝火堡垒 / HEARTHHOLD 0.9.0-preview
Unity 3D Windows x64 离线试玩版

本构建使用 KayKit Medieval Hexagon Pack、Adventurers Character Pack 与 Quaternius RPG Character Pack 的 CC0 三维资产。作者、原始下载页和许可证记录见项目根目录 THIRD_PARTY_ASSETS.md；CC0 不要求署名，但项目保留来源记录。

近期视觉更新：五名主力兵使用独立三维骨骼动画；铁卫有举盾挥击，翼骑有网格翅膀拍动，炼金师有投掷起手。旧版风暴塔满血数值已兼容迁移；无需删除旧存档。

运行：完整解压压缩包后，双击 Hearthhold.exe。
不要只复制exe；Hearthhold_Data、MonoBleedingEdge、UnityPlayer.dll及其他同级文件均为运行所需。
发布包运行时不需要安装Unity。

0.9.0更新：
兵种扩展为8种：先锋、游侠、铁卫、破城手、翼骑、炼金师、医师、唤灵师。翼骑从空中绕墙，炼金师范围攻击，医师治疗友军，唤灵师周期召唤幽影。
防御扩展为6种战斗职责：地面单体、地空单体、带盲区远程范围、对空高伤、近程地空范围和递增光束。
新增战吼、霜封、裂地，与疗愈构成4种法术。按Q/Z/X/C选择后点击战场；按F再点击建筑下达集火令。

0.8.0更新：

新增每场2次的“集火令”：开战后按E或点左侧按钮，再点击存活的敌方非城墙建筑，让在场部队集中进攻7秒。下令不直接造成伤害，也不能跳过城墙。
重弩炮现在对密集士兵造成少量溅射伤害，哨塔仍为单体攻击；分批或分侧投放有利于减少损失。

第一次玩：
1. 点击左侧“收取”，获得已经产生的资源。
2. 选择底部建筑，再点击地图空地建造。
3. 点击建筑，按M移动、按U升级、按Delete申请拆除。
4. 按I查看兵种说明，按T调整和训练本次远征阵容；兵营管容量、训练营管解锁、实验室管等级。
5. 点击右下角“出发远征”；初期按1投先锋吸引火力，按2投游侠后排输出。训练营升级后按3投铁卫、按4投破城手。
6. 按Q疗愈、Z战吼、X霜封、C裂地；按F点击敌方建筑下达7秒集火令。未部署士兵结算后返回。

常用操作：
WASD / 中键拖动：移动镜头
滚轮 / Home：缩放 / 镜头复位
R / Shift+R：镜头顺时针 / 逆时针旋转45度
右键 / Esc：取消操作
M / U / Delete：移动 / 升级 / 拆除所选建筑
Ctrl+Z / Ctrl+Y：撤销 / 重做建筑移动
C：收取资源
1—8：切换兵种；Q/Z/X/C：疗愈/战吼/霜封/裂地；F：集火令；I：兵种图鉴；T：编队与训练
F1：帮助；F11：全屏

存档位于Unity的Application.persistentDataPath，由系统按当前Windows用户管理。
原生试玩版与Unity版默认使用不同存档位置，不会自动互相覆盖。
未结算战斗不覆盖聚落存档；战斗中正常退出不给奖励并返还完整出征阵容。
