篝火堡垒 / HEARTHHOLD
Unity 3D Windows x64 离线试玩版

运行方式：
1. 完整解压发布包。
2. 双击 Hearthhold.exe。
3. 不要单独复制 exe；Hearthhold_Data、MonoBleedingEdge、UnityPlayer.dll 和其他同级文件都是运行所需。

主要玩法：
- 建造、移动、升级和拆除聚落建筑；城墙支持连续建造、整排选择和整排移动。
- 兵营决定部队容量，训练营解锁兵种，实验室升级兵种与法术。
- 8 类兵种、4 类法术、英雄和协同战宠参与十关远征。
- 英雄与普通部队独立；战宠随英雄出战，英雄阵亡后仍可独立攻击。

常用操作：
WASD / 鼠标中键拖动：移动镜头
滚轮 / Home：缩放 / 复位
R / Shift+R：旋转镜头
B：建筑目录
T：编队与训练
I：兵种图鉴
M / U / Delete：移动 / 升级 / 拆除
Ctrl+Z / Ctrl+Y：撤销 / 重做移动
1—8：选择兵种并点击战线投放
H / V：选择英雄 / 使用英雄技能
Q / Z / X / C：选择法术
F：集火令
F1 / F11：帮助 / 全屏

存档：
存档由 Unity 写入当前 Windows 用户的 Application.persistentDataPath。更新版本前建议备份 village.xml 和 village.xml.bak。

资产：
本构建使用 KayKit 与 Quaternius 的 CC0 三维资产。完整来源和许可证记录见源码仓库 THIRD_PARTY_ASSETS.md。项目不包含其他商业游戏的原始素材。

验证环境：Unity 6000.6.0f1 / URP 17.6.0，Windows 11 x64。
本版本仍处于原型开发阶段，并非完整商业游戏。
