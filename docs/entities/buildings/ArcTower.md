# 风暴塔 · ArcTower

- 定位：地空中程范围电弧，针对紧密军团。
- 轮廓：顶部放电转子；二级接地杆和侧鳍，三级放电冠。
- 当前代码：`ModelViews.AddStormMechanism`、`ModelIdentityArt.UpgradeArcTower`、`ArticulatedModelAnimator.ConfigureStormTower`、`Rules.Buildings[ArcTower]`、`DefenseIdentityEffects.SpawnArcStrike` 的折线闪电。
- 后续动作：范围伤害已有，电弧还需按实际受击目标逐个跳跃；当前折线只连主目标。
- 验收：旋转转子和范围击中能在实战镜头辨认；与灼光塔的持续锁定不同。
