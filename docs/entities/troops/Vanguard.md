# 先锋 · Vanguard

- 职责：低营位均衡近战，组成清边与入墙后的基础队形；不会像破城手那样优先墙。
- 三维识别：持剑、盾脊与头盔；二级盾脊加厚，三级分叉盔饰改变头部剪影。
- 动作/VFX：使用导入剑击动作；接近墙时攻击挡路墙段，命中为近战冲击而非箭矢。
- 当前代码：`Rules.Troops[Vanguard]`、`ModelViews.AddVanguardSculpt`、`ModelIdentityArt.AddTroopIdentityUpgrade`、`Battle.StepUnit`。
- 验收：低等级与高等级从默认镜头看见盾/盔形差异；不能与铁卫共用重甲轮廓。
