# 燧爪 · CinderFox

- 职责：跟随绑定英雄协同攻击，英雄阵亡后独立索敌；不占营位。
- 三维识别：长耳、尖嘴、细躯和一条锥形火尾；二级项圈，三级尾端余烬。
- 动作：头、四肢和尾巴有独立关节；前扑攻击，受击短缩，死亡侧倒。
- 代码：`Battle.StepUnit` 战宠跟随分支、`ModelViews.CreateCinderFoxSculpt`、`CinderFoxArtAnimator`、`ModelIdentityArt.AddPetIdentityUpgrade`。
- 当前缺口：精模级皮毛与尾焰粒子尚未完成；当前是项目自制 3D 原型。
- 验收：受击后恢复原材质颜色，且绕到背面仍是立体狐狸，不是看板贴图。
