```text
本项目为面向 Windows PC 的三维聚落建造与回合制攻城策略游戏，主要功能模块如下：

一、聚落建造模块。提供四十乘四十格网格地图，支持建筑的放置、移动、升级、拆除与撤销重做；拥有数量上限、地基尺寸校验、占用冲突检测与五十比例的资源返还规则；石墙支持连续建造、整排选择、整排升级与整排移动，并有独立的阵型编辑模式，可在编辑完成后一次性提交整体布局。

二、资源与经济模块。金币与晶露两种常规资源由金矿、晶露池持续产出，支持离线收益结算、仓储上限、资源收取与成就奖励；建筑升级、兵种训练、英雄与战宠养成共享统一的经济规则。

三、军事养成模块。兵营提供营位容量、训练营负责兵种解锁、实验室研究兵种与法术等级，三者职责分离；造兵为零等待，支持单兵、批量与预设编队，编队按营位自动裁剪。

四、兵种与法术模块。包含先锋、游侠、铁卫、破城手、翼骑、炼金师、医师、唤灵师八类兵种，具备地面、空军、重甲、攻城、远程、范围、治疗、召唤等职责分工；另有疗愈之雨、战吼、霜封、裂地四类战术法术与集火令指挥能力。

五、英雄与战宠模块。英雄拥有独立殿堂进行解锁与升级，不占兵营营位；战宠与英雄绑定后协同出征，英雄阵亡后仍可独立索敌作战，并配有实时三维预览的英雄图鉴界面。

六、战斗与关卡模块。内置十关战役，实现四方向带墙体代价的 A* 寻路、破墙开路、飞行绕墙、防御建筑索敌与反击、范围与溅射伤害、飞行单位优先级、锁定增伤、治疗与召唤、战斗结算与星级评定；战后按缺员自动补兵。

七、界面与辅助模块。包含聚落抬头显示、建造目录、编队与训练、兵种图鉴、研究、发展路线、出征编成、英雄殿堂与战宠小屋等界面，支持鼠标全流程操作与可选的键盘快捷键；提供首次出征教学、建筑与兵种三维动画预览、动画详情舞台以及可切换视角的镜头控制。
```

## 四、项目实现（必填，≥40 中文字符）

**填写稿（去空白后 381 字）：**

```text
本人独立承担了本项目的全部工作：需求梳理与玩法设计、进度与经济规范文档的编写、游戏规则层的架构设计与编码、Unity 客户端表现层与全部界面的实现、三维资产的接入与程序化几何的生成、寻路与战斗系统的算法实现、自动化测试与构建脚本的编写，以及 Windows 平台的构建打包与发布验证。

技术栈与架构：项目使用 C# 语言，基于 Unity 6000.6.0f1 引擎与 URP 17.6.0 渲染管线，目标平台为 Windows x64；代码分为三个程序集层次——Core 为完全不依赖 Unity 的纯规则层，包含数据模型、规则表、经济系统、战斗模拟、寻路算法与存档序列化；Runtime 为表现层，负责三维网格生成、骨骼动画播放、摄像机与输入、即时模式界面以及战斗特效；Editor 层负责工程初始化、场景生成与自动构建。这一分层使玩法规则可脱离引擎与表现独立测试。

主要技术与亮点：其一，整数坐标与定点步长的确定性模拟，地图坐标以每格一千单位表示，战斗采用二十赫兹固定步长与确定性状态指纹，使同一输入可复现同一战局，便于自动化回归与未来回放校验；其二，自研的四方向 A* 寻路与带墙体通行代价的全图距离场，让地面单位的选目标与寻路共享同一代价口径，避免"隔墙目标看似很近却要绕很远"的错误决策，破墙后距离场按地图修订号失效并触发在场单位重新选目标；其三，完全原创的规则数据、数值与中文文案，第三方资源仅使用知识共享零条款的模型并在仓库中完整登记来源与许可证；其四，规则层不含任何引擎类型，配合两百余项核心规则检查与多组成品渲染烟雾测试用例，可在无人值守的构建脚本中完成从编译到截图的端到端验证。

难点与解决：一是分层解耦，将全部游戏规则从引擎中剥离，使同一份 Core 源码可被不同宿主复用；二是墙体通行代价既要影响寻路又要影响选目标，需要统一代价口径并在建筑被摧毁后正确失效缓存；三是旧版本存档迁移，需要在不吞掉玩家既有资产的前提下把旧训练队列安全转换成即时成军并退款，且数据异常时拒绝读入而非静默覆盖；四是三维表现与逻辑占用的一致性，建筑地基、选中框、碰撞体、投影与保存坐标必须使用同一套占位定义，避免旋转镜头后出现错位。
```
