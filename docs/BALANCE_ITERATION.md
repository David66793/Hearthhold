# 战斗与造型迭代记录

本轮优先解决三个法系兵共用同一 Mage 外形的问题。三者现分别使用 Mage、RogueHooded、Rogue 三套不同底模：炼金师增加药瓶背架与炼金弹，医师增加白色长袍、红十字、医疗包与治疗杖，唤灵师增加深色长袍、兜帽、双角与紫色召唤宝珠。其余五种兵也增加了符合职责的盾、箭筒、炸药桶或飞行翼等配件。它们仍基于 CC0 KayKit 角色网格，属于可玩的 3D 造型细化，并非最终手工精模。

## 平衡改动

- 先锋与游侠的单营位生命、伤害略降；铁卫、破城手、翼骑、炼金师、医师、唤灵师的专长数值适度提高。目的是让进阶混编比基础兵堆叠更有价值。
- 风暴塔从短程弱溅射改为中程范围防御，并仅在第 2—4 关额外布置；第 1 关保留教学难度。
- 敌方防御伤害按关卡逐步提高。旧式整数除法导致前六关的实际伤害几乎不变，此处改为每关约递增 12%，第 9 关后封顶。

下表是固定脚本的模拟结果：45 营位的未研究基础编队，从西侧一次性投放，每场在固定时刻尝试两次治疗。数字是 `摧毁率 / 星数`，不代表玩家采用更好的下兵时机后的上限。

| 关卡 | 调整前 | 调整后 |
| --- | --- | --- |
| 1 松林前哨 | 100% / 3 | 100% / 3 |
| 2 河谷营地 | 100% / 3 | 100% / 3 |
| 3 灰岩要塞 | 100% / 3 | 100% / 3，存活数由45降至36 |
| 4 双桥关 | 100% / 3 | 100% / 3，存活数由44降至33 |
| 5 霜木环堡 | 100% / 3 | 90% / 2 |
| 6 赤土兵站 | 63% / 2 | 54% / 2 |
| 7 风暴高台 | 66% / 2 | 41% / 1 |
| 8 月湾城寨 | 53% / 2 | 38% / 1 |
| 9 黑松迷阵 | 28% / 0 | 28% / 0 |
| 10 晨火王庭 | 0% / 0 | 0% / 0 |

75 营位、三级科技的进阶混编在同一脚本下，第 8 关可得 3 星，第 9、10 关可得 2 星。第 8—10 关仍需要更好的编队与投放操作才能稳定取得高星。本轮已把这些目标写入自动平衡测试，防止后续数值修改让初级兵重新碾压中后期关卡。
