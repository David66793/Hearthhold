# 战斗与造型迭代记录

## 家乡玩法对标落地顺序（2026-09）

依据 [家乡玩法研究](COC_HOME_VILLAGE_BENCHMARK_2026.md) 的“阶段引入新决策、横向配兵、法术窗口、攻防双向元游戏”四项原则，本项目只借鉴机制语法，不复用名称、数值表、阵型、美术或私服代码。进度与消耗以 [强制规范](PROGRESSION-AND-ECONOMY-CONTRACT.md) 为准。

1. **本轮：法术区域可读性。** 去除与玩法无关的地图黄色十字和自动通知；疗愈、战吼、霜封改为战斗时钟驱动的持续区域，能覆盖后来进入的目标，特效在规则结束时同步消失。裂地保持瞬时破墙，并强化碎裂反馈。验收包括持续时长、预释放、进入/离开范围、到期恢复及 Windows 战斗截图。
2. **下一轮优先：英雄构筑。** 按规范实装两装备槽和四件原创基础装备，让相同英雄在抗伤、开路、团队支援之间做选择；装备必须改变战斗规则，不只增加面板伤害。先补固定对照战役和存档迁移测试，再开放制作材料。
3. **随后：堡5阵型元游戏。** 陷阱、独立防守阵型、战斗日志与基础回放一起交付，避免只有“造更多防御”的空阶段。要求进攻方可通过侦察和配兵应对，同一陷阱布局能改变至少两种编队的结果。
4. **再后：堡6攻城分支。** 地面开路器械与空投器械各一类，均需明确营位/载荷、部署限制与防御反制。不得在此之前提前塞入空壳工坊或未闭环材料。

每个阶段复核官方机制变化，但维持 Hearthhold 的原创名称、独立规则与零等待造兵原则。每项新机制至少要有成功、拒绝、跨等级、旧存档和固定战役平衡用例。

## 路径感知目标选择

此前部队先按直线距离选建筑，再用 A* 寻路，容易出现隔墙建筑看似近、实际绕路很远却被全队盯住的情况。现在地面兵在目标选择阶段使用与寻路相同的通行/破墙权重；一次计算的距离场按起点格、兵种破墙能力与地图修订号复用，建筑被摧毁后清空。地图因破墙或拆毁建筑改变后，在场士兵也会重新选目标。空军仍按直飞距离选目标，兵种职责偏好和集火令优先级保持不变。战斗兵种卡显示主攻目标，方便观察新行为。

同一套固定脚本与兵力下，第7关（测试索引6）基础编队由 41%/1 星变为 50%/2 星；第8关为 46%/1 星，第9、10关基础编队仍为 0 星。75营位满科技专业编队在第9、10关仍可各得2星。此结果是路径策略变化后的回归基线，不代表人工玩家胜率；第7关难度后续仍需真人试玩确认。

后续八方向寻路修正（2026-09-26）：空地允许斜向前进，但不允许从建筑或墙角斜穿；普通地面兵穿墙权重下调，让短距离破墙优于绕整排城墙，挡路墙段会成为当前攻击目标。固定脚本回归中，测试索引6/7/8/9的基础编队分别为 41%/1 星、46%/1 星、28%/0 星、0%/0 星；满科技专业编队在索引8/9分别为 50%/2 星、60%/2 星。此前百分比保留为历史记录，不应当作当前平衡基线。

本轮优先解决三个法系兵共用同一 Mage 外形的问题。三者现分别使用 Mage、RogueHooded、Rogue 三套不同底模：炼金师增加药瓶背架与炼金弹，医师增加白色长袍、红十字、医疗包与治疗杖，唤灵师增加深色长袍、兜帽、双角与紫色召唤宝珠。其余五种兵也增加了符合职责的盾、箭筒、炸药桶或飞行翼等配件。它们仍基于 CC0 KayKit 角色网格，属于可玩的 3D 造型细化，并非最终手工精模。

## 平衡改动

- 先锋与游侠的单营位生命、伤害略降；铁卫、破城手、翼骑、炼金师、医师、唤灵师的专长数值适度提高。目的是让进阶混编比基础兵堆叠更有价值。
- 风暴塔从短程弱溅射改为中程范围防御，并仅在第 2—4 关额外布置；第 1 关保留教学难度。
- 敌方防御伤害按关卡逐步提高。旧式整数除法导致前六关的实际伤害几乎不变，此处改为每关约递增 12%，第 9 关后封顶。
